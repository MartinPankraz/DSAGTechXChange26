## Lab prerequisites

- [SAP BTP trial account](https://www.sap.com/products/technology-platform/trial.html) (in guided workshops, this will be provided by the instructor)
- [GitHub account](https://github.com/signup) (alternatively, you can clone the repo locally and run the devcontainer in VS Code, but Codespaces is recommended for the best experience)
- [Free trial of Microsoft Sentinel](https://www.microsoft.com/en-in/security/business/get-started/start-free-trial) (in guided workshops, this will be provided by the instructor)
- [Microsoft Authenticator app](https://www.microsoft.com/en-us/security/mobile-authentication-apps) (or any other TOTP app for Azure login)
- SAP BTP subaccount [onboarded to Microsoft Sentinel for SAP BTP](https://learn.microsoft.com/azure/sentinel/sap/deploy-sap-btp-solution)
